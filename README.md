# My Doctor

A simple, installable web app for Phillip Alvaranga in Frisco, TX.

Use it to find doctors near Frisco, track blood pressure, keep a medicine list with reminders, save appointments and visit notes, and jot down questions for your doctor.

**Live:** https://phillipalvaranga-arch.github.io/doctor-app/

## Privacy

Everything you type stays on this device, in this browser. There is no account and no server copy. The app never asks for a Social Security number, insurance member ID, card or bank number, or a password.

This app is not medical advice and is not an emergency service. If you think you are having a medical emergency, call 911.

## Install

- **Android tablet or phone:** Open the site in Chrome, then use the menu and choose Install app or Add to Home screen.
- **Windows:** Open the site in Chrome or Edge and use the install icon in the address bar.

## Backup

Use **More → Download backup** to save a JSON file, and import it if you get a new device or switch browsers.
